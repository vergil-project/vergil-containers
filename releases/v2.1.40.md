
# Release 2.1.40 (2026-11-13)

## Bug fixes

- **suppress krb5-libs HIGH CVEs blocking the dev-pkg-rhel:9 publish (#867)**
* fix(security): ignore the server-side krb5-libs CVEs blocking dev-pkg-rhel:9

UBI 9 does not yet ship krb5-libs 1.21.1-10.el9_9.2. Twelve of the fourteen gating CVEs are in KDC, kadmind or GSS-RPC server code the image never runs. CVE-2026-119079 and CVE-2026-71199 are fixed in libkrb5 itself and await a ruling. Ref #866.

* fix(security): ignore the two libkrb5 krb5-libs CVEs on a maintainer ruling

CVE-2026-119079 and CVE-2026-71199 are fixed in libkrb5, which curl and git load. The maintainer ruled to suppress both rather than wait for UBI 9 to publish the fixed krb5-libs: the first is reachable only during Kerberos authentication against an attacker-controlled KDC or server, and the second only in a ticket acceptor. The group's removal condition covers them. Ref #866.

- **write and remove toolchain pins in lifecycle add and drop PRs (#868)**
An add PR resolves its new series' pin (and a missing rustup-init) through the toolchain resolvers, a drop PR removes a pin only when the edited manifest no longer needs it, and CATALOG.md is regenerated from the edited pins. render_change takes a required fetch, threaded through sync_prs and _publish_change from publish.main, and never writes to the shared checkout. Includes the 1.100 three-digit-minor tests (spec 6.6).
