
# Release 2.1.23 (2026-08-11)

## Bug fixes

- **pin container TypeScript to the stable 5.x line (#533)**
T1 installed the shared-analysis `typescript` unpinned, which now resolves to the 7.0.2 native (Go) port line ("tsgo"). For v1 the epic standardizes on the stable TypeScript 5.x line; the native port is deferred to the follow-on brainstorm (#286). Constrain the global install to `typescript@5` so T4's strict tsconfig, its docs (T8), and end-to-end validation (T10) all target the same stable compiler.

`@5` is a major-line constraint that floats within the 5.x major, so it stays a language-major choice under the float doctrine (epic #155), not an exact x.y.z reproducibility pin: extract_pins.py captures only three-component pins, so no docker/pins/pins.yml entry is required and the pins gate stays green. tsc now reports 5.9.3 in both ts-node:24 and ts-node:22; typescript-eslint@8.67.0 dedupes onto typescript@5.9.3 (no peer-range breakage); the T1 smoke test (npm ci + tsc --noEmit + vitest) passes on both images.
