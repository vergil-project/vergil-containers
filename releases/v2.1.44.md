## Features

- **detect new Rust series from the stable channel, not endoflife.date (#940)**
  endoflife.date lags Rust's releases by days, so the Rust adapter now reads channel-rust-stable.toml and adds every series after endoflife.date's newest cycle up to the stable one, dated from its .0 release's channel manifest. endoflife.date stays the cross-check: a newer cycle it dates on or before the stable release fails the check. The channel readers live beside rust_release in resolve_toolchains. Refs #910.
- **leave repo-declared TypeScript tools to the repo (#942)**
  The ts-node image keeps prettier and license-checker and drops typescript, eslint, typescript-eslint, vitest and @vitest/coverage-v8, under vergil-tooling's tool-ownership guideline. The smoke project now declares those tools at the accepted majors (typescript 6, typescript-eslint 8, eslint 10, @eslint/js 10, vitest 5, @vitest/coverage-v8 5), installs them with npm ci --ignore-scripts and runs them from node_modules/.bin, and asserts tsc, eslint and vitest are not on the image's PATH. checks.sh checks the image tools only. Ref #925
