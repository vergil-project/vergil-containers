
# Release 2.1.19 (2026-08-05)

## Refactoring

- **centralize pip vendored-SBOM skip in trivy.yaml, drop per-image rm (#499)**
The base/python templates deleted pip/_vendor/bom.cdx.json to keep Trivy from reporting pip's vendored deps (setuptools, msgpack) as image CVEs (#481). Replace that per-image rm with a single scan.skip-files entry in trivy.yaml.

Both publish scans load trivy.yaml from /workspace -- the amd64 shared action and the arm64 inline scan -- so one skip covers both platforms. (The shared action also skips it now, vergil-actions#798, but only on the amd64 path it runs; the arm64 inline scan is not covered by the action, so the repo-level trivy.yaml is the correct single source.) This removes the Dockerfile duplication and stops mutating pip's internals in the image.
