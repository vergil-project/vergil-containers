
# Release 2.1.26 (2026-08-15)

## Chores

- **reconcile .gitignore to baseline + restagger ops.yml cron (#553) (#554)**
Rollout for epic #311: superset of the centralized .gitignore baseline and restagger the ops.yml cron from the shared 15 6 to the deterministic per-repo minute.

- **suppress CVE-2026-33818 (encoding/asn1 DoS in bundled Go CLIs) (#555) (#556)**
The nightly Ops run failed the Trivy CRITICAL/HIGH gate on five images (prod/dev rust:1.92, rust:1.93, and dev-go:1.26) with CVE-2026-33818, a HIGH encoding/asn1 denial of service in the Go stdlib (fixed in go1.25.13 / go1.26.6 / go1.27.0-rc.3).

The carrier is the prebuilt gh, actionlint, nfpm, and shfmt binaries in the common layer, each compiled upstream with Go 1.26.1-1.26.5. The pass/fail split was a scan-timing race: the CVE entered Trivy's vuln DB mid-run, so only the slowest-building images were still scanning after the refresh. No installable fixed carrier exists today.

These tools are static linters / known-host API clients operating on local files; none decodes attacker-controlled ASN.1/DER, so the vulnerable path is not exercised. Remove once the bundled tools ship rebuilt binaries.

- **suppress CVE-2026-56853 (net/http unencrypted HTTP/2 in bundled Go CLIs) (#557) (#558)**
The post-merge CD publish on develop (run 31881337944) failed the Trivy CRITICAL/HIGH gate on every dev image with CVE-2026-56853, a HIGH net/http unencrypted-HTTP/2 issue in the Go stdlib (fixed in go1.25.13 / go1.26.6 / go1.27.0-rc.3).

This is a sibling of CVE-2026-33818 (#555) from the same Go security release, carried by the same prebuilt gh, actionlint, nfpm, and shfmt binaries (plus scorecard/trivy/tofu on dev-base). It entered Trivy's vuln DB between the nightly Ops run #555 diagnosed and the post-merge CD run, so #555 could not have caught it.

The affected h2c path is server-side; these carriers make outbound HTTPS calls to known hosts only and never serve untrusted HTTP/2, so it is not exercised. No installable fixed carrier exists yet. Remove alongside CVE-2026-33818 once the bundled tools ship rebuilt binaries.

- **suppress remaining Go 1.26.6/1.25.13 stdlib CVEs (release batch) (#559) (#560)**
Closes out the Go 1.26.6/1.25.13 security release (2026-08-13, 10 CVEs) that #555 (encoding/asn1) and #557 (net/http) suppressed piecemeal as it propagated into Trivy's DB in waves. Adds the four remaining stdlib CVEs in one batch: CVE-2026-56858 (html/template), CVE-2026-56859 (encoding/xml), CVE-2026-56860 (net/url), CVE-2026-56862 (crypto/tls).

Trivy flags Go stdlib vulns by the toolchain version baked into each binary with no import-reachability analysis, so every stdlib CVE in this release is guaranteed to gate the prebuilt Go CLIs (gh, actionlint, nfpm, shfmt; plus scorecard/trivy/tofu on dev-base) compiled with Go 1.26.1-1.26.5. Pre-empting the rest is evidence-based, not speculative.

The two x/mod members (CVE-2026-56864, CVE-2026-56865) are deliberately not suppressed: they are module-version-based, and no carrier reports a vulnerable x/mod in the current scans. None of the four suppressed paths (browser template rendering, untrusted XML decode, attacker-controlled URL resolution, server-side TLS) is exercised by these outbound-only linters. No installable fixed carrier exists yet; remove the whole release block once the tools rebuild with go1.25.13+/1.26.6+.
