
# Release 2.1.14 (2026-08-04)

## Features

- **clang dev/prod images + shared C++ base (#470)**
Add the Clang/LLVM C++ dev-container family and the shared, compiler-agnostic analysis layer every C++ image inherits (epic vergil-project/.github#207, task T1).

Toolchain discovery (prebuilt-only, spec 3.5): pin Clang majors 20 (apt.llvm.org llvm-toolchain-trixie-20, 20.1.8) and 19 (also Debian trixie main, 19.1.7) as prebuilt stable binaries; the target 19/20 pins qualify so the 18/19 fallback is not needed. Decision recorded in docker/cpp-clang/README.md.

Structure matches the repo's existing image idiom: docker/cpp-clang/Dockerfile.template (FROM debian:trixie-slim, composes the same validation fragments as the rust image), with the shared analysis toolset (clang-format, clang-tidy, cppcheck, cmake, conan 2, gcovr) expressed as the common/cpp-analysis.dockerfile fragment rather than a FROM-chained base image, since language images here compose fragments. CC/CXX default to clang with libstdc++.

Smoke check (docker/cpp/smoke + smoke-test.sh, wired into build.sh): a trivial CMake + Conan 2 project compiles, links, and runs under each Clang image. No exact x.y.z pins introduced, so the pins gate stays clean.
