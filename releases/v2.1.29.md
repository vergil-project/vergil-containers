
# Release 2.1.29 (2026-10-21)

## Bug fixes

- **verify hadolint against checksums.sha256 (#603)**
hadolint 2.15.1 no longer publishes a per-binary .sha256, so the validation-tools layer 404'd and broke every image build. Select the exact hadolint-${HL_ARCH} line (whole-line anchored grep) from the release's single checksums.sha256 and verify it with sha256sum -c; an unmatched line fails the build. Update the pins.yml/CATALOG.md reason text. Ref vergil-project/vergil-containers#602

- **install vergil-tooling before the image Trivy scans (#607)**
The shared Trivy action runs vrg-sarif-filter before uploading SARIF for image scans, but cd-docker-publish.yml never put vergil-tooling on PATH, so every amd64 scan failed with 'command not found' and no SARIF reached code scanning. Add the vergil-actions setup/vergil step before the amd64 Trivy scan in both build-scan-push and publish-base. The arm64 scan runs Trivy inline and is unchanged.

- **clear the image publish Trivy gate (ten fixed HIGH CVEs) (#608)**
Bump nfpm 2.47.0 -> 2.48.0 and trivy 0.75.0 -> 0.76.0 (both built with go1.27.2, x/net 0.60.0). This clears the nfpm and trivy carriers of CVE-2026-78667, CVE-2026-78669 and CVE-2026-97031, and removes the only carrier of CVE-2026-56854 (x/crypto/ssh in nfpm). CATALOG.md regenerated.

Install npm@^12.2.1 instead of npm@latest. npm 12.2.1 bundles brace-expansion 5.0.12 and undici 6.29.0, which fixes CVE-2026-102276, CVE-2026-102278 and CVE-2026-19534. The latest dist-tag is still 12.2.0. Revert to npm@latest once latest is 12.2.1 or newer.

- **fix the dev-go 1.26 build and retire the Go 1.25 image (#609)**
* fix(docker): pin go tools per Go version so both dev-go images build

The Go images build with GOTOOLCHAIN=local, so a go install @latest whose go.mod needs a newer Go fails the build. govulncheck (x/vuln v1.8.0+) and goimports (x/tools v0.50.0+) now need Go 1.26, and go-test-coverage v2.20.0 needs Go 1.27.

Go 1.25 now holds govulncheck v1.7.0 and goimports (x/tools) v0.49.0, alongside the existing golangci-lint and go-test-coverage holds. Go 1.26 holds go-test-coverage v2.19.0. Each is the newest release whose go directive the image's Go satisfies; every other tool stays on @latest. pins.yml and CATALOG.md record the new pins.

- **clear the image publish Trivy gate (Go stdlib CVE-2026-111943, x/text CVE-2026-56851) (#626)**
Bump opentofu 1.13.1 -> 1.13.2 and trivy 0.76.0 -> 0.76.1. Both new releases are built with go1.27.3, which fixes CVE-2026-111943 (crypto/x509 intermediate-certificate denylist), so those carriers are fixed rather than ignored. CATALOG.md regenerated.

## Features

- **generate every version list from one manifest (#623)**
Add docker/versions/manifest.yml as the single source of truth for the language versions this repo builds, seeded with the exact current publish matrix. docker/versions/generate.py writes matrix.json (the cd-docker-publish build matrix, now read via fromJSON), window.json (the published window), the build.sh build and smoke-test lines, the package-cleanup lists (adding the missing cpp-clang, cpp-gcc and ts-node packages), the Dockerfile ARG defaults and the docs version tables. report_exposure reads its image matrix from the manifest. The CI pins job and scripts/bin/validate-custom run generate.py --check and the versions tests. Ref vergil-project/vergil-containers#613

- **drop Ruby and GCC 13 from the image matrix (#625)**
* feat(versions): drop Ruby and GCC 13 from the image matrix

Remove the ruby family and cpp-gcc 13 from docker/versions/manifest.yml and regenerate every derived list (publish matrix, window.json, build.sh, package-cleanup lists, README/CLAUDE.md/docs tables). Delete docker/ruby/, the Ruby-only .trivyignore entries and the gem-install hadolint exemption, and update the cpp-gcc README, docs and tests. Existing GHCR packages are left in place (spec 8.2). Ref vergil-project/vergil-containers#619, epic vergil-project/.github#407.
