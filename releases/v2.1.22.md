
# Release 2.1.22 (2026-08-11)

## Bug fixes

- **triage CVE-2026-71556 (go-git in nfpm) to unblock CD publish (#527)**
The Trivy CRITICAL,HIGH gate began failing on every dev image after the vulnerability DB picked up CVE-2026-71556 (HIGH, go-git v5.19.1, bundled in nfpm). No fixed carrier is installable — nfpm latest (2.47.0, the current pin) still vendors go-git v5.19.1 — so suppress the CVE with a justification per the established .trivyignore convention. The vulnerable clone-then-worktree path is not exercised: nfpm assembles packages from local files and does not clone untrusted repositories. Remove once nfpm vendors go-git >= 5.19.2.
