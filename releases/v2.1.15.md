
# Release 2.1.15 (2026-08-04)

## Bug fixes

- **clear v2.1.14 docker-publish Trivy gate (setuptools + 3 suppressions) (#476)**
Four new HIGH CVEs broke the v2.1.14 docker-publish gate across all 13 images.

- CVE-2025-47273 (setuptools 70.3.0 -> 78.1.1): reachable fix. Bump setuptools on the base + python templates (the system pip env from python:3.x-slim ships 70.3.0). The four language images install python tooling into isolated uv venvs and are unaffected.
- GHSA-6v7p-g79w-8964 (msgpack), CVE-2026-69152 (brace-expansion), CVE-2026-69192 (ip-address): suppressed. Each is fixed upstream but not reachable in any installable carrier the images can pull today (pip vendors msgpack 1.1.2 through 26.2; npm@latest 12.0.2 still bundles brace-expansion 5.0.7 and ip-address 10.2.0), and none is exercised in the images' runtime usage.


## Features

- **gcc dev/prod images on shared C++ base (#475)**
Add the GCC compiler family for C++ images (epic vergil-project/.github#207 task T2), mirroring the T1 Clang structure: a docker/cpp-gcc/Dockerfile.template that FROMs debian:trixie-slim, composes the shared common/cpp-analysis fragment (reused, not duplicated), installs the pinned GCC major, and sets CC=gcc/CXX=g++ with GCC's native libstdc++.

Pins gcc-14 (primary) and gcc-13 (secondary): gcc-15 is not cleanly prebuilt for debian:trixie-slim (apt Candidate: none), triggering the spec 3.5/11 fallback to gcc-13/14. Compiler binaries come exclusively from Debian trixie main prebuilt packages, never built from source.

Wires cpp-gcc into generate.sh and build.sh (both pinned majors + per-image smoke). Extends the shared smoke check to assert the analysis toolset (clang-format/clang-tidy/cppcheck/gcovr) is present and runnable, so both families verify it. Both images build and pass the CMake+Conan smoke check under nerdctl.
