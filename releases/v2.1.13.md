
# Release 2.1.13 (2026-07-29)

## Bug fixes

- **clear docker-publish Trivy gate (npm upgrade + residual CVE suppressions) (#462)**
* fix(images): upgrade bundled npm to latest to clear node-tar/brace-expansion CVEs

NodeSource node 22 ships an older npm whose vendored deps carry HIGH/CRITICAL CVEs that break the docker-publish Trivy gate: node-tar CVE-2026-59873 (CRITICAL, gzip-bomb DoS) / CVE-2026-59874 (HIGH), and brace-expansion CVE-2026-13149 (HIGH). Upgrading the global npm to latest before installing markdownlint-cli vendors the patched tar (>= 7.5.19) and brace-expansion (>= 5.0.7), clearing all three across every image. Build-time-only change; npm is not used at container runtime.
