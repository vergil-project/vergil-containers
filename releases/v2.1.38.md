
# Release 2.1.38 (2026-11-11)

## Bug fixes

- **wrap semgrep to cap the stack hard limit, and scan at build time (#827)**
* fix(base): wrap semgrep to cap the stack hard limit, and scan at build time

On Python 3.15 RLIM_INFINITY reads as 2**64 - 1, so semgrep's setrlimits_preexec_fn turns an unlimited stack hard limit into a finite ~5 EiB soft limit for semgrep-core, which segfaults (exit -11) on every scan. base's semgrep and pysemgrep entry points become sh wrappers that lower the hard limit to 2929688 KiB (hard / 3 = 1,000,000,000 bytes, as on Python 3.14) when it is unlimited or larger, warn if they cannot, and exec the tool environment's entry point. checks-invariants.sh now runs a real minimal scan through both entry points, so every image built on base reruns it, and resolves a wrapper's exec target in its core-Python check. Remove the wrappers once semgrep fixes this upstream (#826). Ref #825

* docs(base): document base's semgrep stack-limit wrappers

* feat(base): build base on pkg-ubuntu 24.04 with vergil-python and a side-by-side Node

base is now FROM ${PARENT_IMAGE}, the manifest's new base parent pkg-ubuntu 24.04, and removes the package toolchain marker in its first layer. uv and nFPM come from the parent, so base drops uv's pip install and nfpm.dockerfile.

Four new fragments, which only base includes, install the core runtimes side by side under /opt/vergil/: vergil-apt (the vergil apt repository, set up only after the signing key's primary fingerprint matches the pinned one), core-python (vergil-python<core>, with /usr/local/bin/python3 linked to it), core-node (the pinned nodejs.org tarball, hash-checked, with markdownlint-cli and a wrapper that runs the core node by path) and core-tools (yamllint, ansible-lint, semgrep and mkdocs with mkdocs-material and mike, as uv tools on the core Python). Nothing is pip-installed and no node, npm, npx or pip is on PATH.

generate.py emits base's build args from the manifest's core: section and the core Node pin (CORE_PYTHON, CORE_NODE_MAJOR, CORE_NODE_VERSION and both architectures' hashes), and the docs tables name an entry's manifest parent as its base. base ENV-persists the core series, copies the check scripts into the image and runs checks.sh as its last step.

Ref vergil-project/vergil-containers#779.
