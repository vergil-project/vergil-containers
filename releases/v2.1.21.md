
# Release 2.1.21 (2026-08-11)

## Features

- **node dev/prod image + shared TS base (#522)**
Add the foundational TypeScript container support for epic vergil-project/.github#284 (T1).

New docker/ts-node image (prod-ts-node:24 / dev-ts-node:24) installs the pinned matrix Node major from the NodeSource prebuilt apt channel (never built from source): node-24 primary, discovered as v24.19.0 with npm 11.17.0 on debian:trixie-slim. node-22 (v22.23.2) is confirmed prebuilt and lands in T2 via the same NODE_MAJOR build-arg.

The shared runtime-agnostic analysis toolset (typescript/tsc, eslint + typescript-eslint, prettier, vitest + @vitest/coverage-v8, license-checker) is the plan's Dockerfile.base 'shared base layer', expressed as common/typescript-analysis.dockerfile per this repo's @include-fragment idiom (mirroring common/cpp-analysis from epic #207). Tools float on the leading edge per the repo pinning doctrine (epic #155); no exact npm pins, so no docker/pins entry and the pins gate stays green.

build.sh registers the node-24 build + a build-time smoke check (trivial package.json + tsconfig.json project: npm ci, tsc --noEmit, one vitest run) that also asserts the shared toolset is present. generate.sh registers ts-node. Ref vergil-project/.github#284.
