## Bug fixes

- **suppress CVE-2026-97054 in Go CLIs and ubuntu:26.04's pebble (#973)**
  Go 1.26.11 / 1.27.4 fix an HTTP/1-server-only net/http race (CVE-2026-97054). Every carrier (actionlint, shfmt, tofu, trivy, yq, and pebble from the ubuntu:26.04 base image) is at its newest upstream release, still built on an older Go, and none runs an HTTP/1 server in the images. Suppressed on the maintainer's ruling with a per-carrier removal condition. Ref #971.

- **move the core Python to a managed 3.15 and drop the vergil apt source (#970)**
