
# Release 2.1.18 (2026-08-05)

## Bug fixes

- **suppress oras-go CVE-2026-50163 (no reachable trivy fix) (#493)**
The v2.1.17 docker-publish gate failed on base with one fixed CVE: oras.land/oras-go/v2 CVE-2026-50163 (v2.6.0 -> 2.6.2). It is embedded in two base-only Go binaries, the tofu and trivy binaries. OpenTofu 1.12.5 ships oras-go 2.6.2, but the latest trivy (0.73.0) still ships only 2.6.1, so no trivy release clears it yet -- it cannot be fixed by a bump and is suppressed, joining the sibling CVE-2026-50151 entry.

The gate loads trivy.yaml (ignore-unfixed: true), so only fixed CVEs block; the ~39 Debian status=affected/no-fix findings seen in a raw local scan are non-gating by policy and not triaged here.
